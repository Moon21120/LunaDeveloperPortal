How your API key works

Your Luna API key is used to authenticate requests from your project.

1. Create your key

When you create a Luna API key, Luna generates a unique credential for your project. This key identifies your requests as authorized Luna API requests.

2. Your project sends the key

When your application wants Luna to respond, your server sends the API key with the request. The key is normally sent using the Authorization header.

3. Luna verifies the key

The Luna API checks the key before processing the request. If the key is missing or invalid, the request is rejected.

4. Luna processes your request

Once the request is authenticated, Luna processes your message using Luna's permanent personality and returns the response to your application.

What the API key does

Your key is an authentication credential, not Luna's personality or model configuration.

Your Luna API key gives your project permission to make requests to the Luna API. It tells the API that the request is coming from an authorized developer.

The key does not contain Luna's personality, your messages, or Luna's model. Luna's personality is configured on the Luna server.

Your API key also does not give you access to Luna's private model-provider credentials. Those credentials remain securely stored on the Luna server.

Think of it like a password for your project. Your project uses the key to prove that it is authorized to use the Luna API. Keep it secret and do not publish it in publicly accessible code.

Keep your API key secure

Treat your Luna API key like a password.

Do

Store your key on your server or in a secure environment variable.

Don't

Put your API key directly into public source code, public GitHub repositories, or client-side code where users can inspect it.

Important Anyone who obtains your Luna API key may be able to make requests using your API access. Never intentionally publish or share the key.

Luna's personality

Luna's core personality is built into the API.

Luna has a permanent personality configured by the Luna server. Developers do not need to configure a personality or provide a system prompt.

Your API key authenticates your project. It does not change Luna's personality.
